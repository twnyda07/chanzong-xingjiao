一、最關鍵的一句話

不要把數百位禪師做成數百篇網頁，要做成一張知識圖譜—— 人物頁只是圖譜的其中一種看法。

這句我完全同意，而且它救的是後面幾年： 骨架定對，五家七宗就只是「加資料」，不必再改網站。

二、現在這一期不會白做

我做的「一站一站走完他的一生」，在新架構裡不是被丟掉，是降一層—— 從「全站入口」變成「人物頁裡的一個分頁」。 52 段原典、CHGIS 座標、遇到的人、距離年差、古畫，全部原樣沿用。

真正要改的是入口：六個人可以用「選一位走完」，六百個人不行。

三、資訊架構四層

L0　首頁＝一花開五葉的法脈總圖

首頁不出現任何名單，只有這張圖。滑過一枝，該枝亮起、其餘淡出， 旁邊只出數字：人物數｜世代數｜地點數｜原典段數。沒有一句介紹文字。

一個分際問題，我要先跟你講。 「一花開五葉」這句出自達摩付法偈（景德傳燈錄卷三：「一華開五葉　結果自然成」）， 但把「五葉」解作「五家」是後人的解釋，原偈沒有這樣說。 所以我的做法是：這五個字可以當網站的視覺骨架與導航名稱， 但網站不宣稱「五葉就是五家」這個歷史論斷——那會變成我們在替原典下註解， 違反第零條。導航是導航，史料陳述是史料陳述，兩件事分開。

L1　宗脈頁

例如點「臨濟」，出現一條可展開的世系：惠能 → 南嶽懷讓 → 馬祖道一 → 百丈懷海 → 黃檗希運 → 臨濟義玄 → … → 石霜楚圓 → 黃龍慧南／楊岐方會。 沒有「臨濟宗介紹」這種現代文字，就是一棵可以點的樹。

L2　人物頁

頂部只給結構化事實：法脈位置｜年代｜主要地點｜師｜法嗣｜原典段數｜事件數。 下面是六個資料視圖（不是文章章節）：

生涯原典公案 相遇的人地點法脈 文物（有才出現）

「生涯」就是現在這一期做好的一站一站走完一生，原封不動搬進來。

L3　公案／事件頁（第二期最該新增的一層）

公案不該只是人物頁裡的一段文字，它要變成獨立的節點。 例如「南泉斬貓」可以同時連到：南泉普願、趙州從諗、東西兩堂、地點、年代、 出現在哪幾部原典、各本的異文。

於是整個網站的核心關係變成：

禪師 ←→ 事件 ←→ 禪師 事件 ←→ 地點 事件 ←→ 原典 禪師 ←→ 法脈

四、四個維度，地位不一樣

維度地位為什麼
法脈主骨架禪宗的自我認同就是師承，這是唯一能撐起數百人的軸

其餘全部只能當篩選器：師父、弟子、寺院、出生地、示寂地、經號、有無畫像……

朝代不要當主導航。唐／五代／宋很好用， 但用朝代切會把師承關係切斷——師父在唐、弟子在五代，一刀下去就斷了。

六、進站前三十秒

第一屏不要有搜尋框＋六百個名字＋地圖＋年表＋五宗介紹。只有那棵樹。

第一屏一花開五葉的法脈圖。中央是達摩，往下到惠能，之後分枝， 最後停在五個大節點。滑過一枝就亮起，只出數字不出介紹。
第二屏點「臨濟」→ 左邊法脈、右邊同步時間軸、下面一張小地圖。 三個維度同時定位。

點擊路徑只有三步：首頁 → 一葉 → 一枝 → 一人。 不是「首頁 → 六百人名單 → 自己找」。

  1. 先不要急著加第七位禪師。先把六張表的結構定死。
