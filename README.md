# 禪宗．祖師行腳

達摩 → 慧可 → 僧璨 → 道信 → 弘忍 → 惠能，六位祖師走過的路、遇見的人、說過的話。
寶嚴山寶嚴禪寺．兒童互動教材。

## 這個站的規矩

- **畫面上祖師說的每一句話，逐字出自原典**，附經號、卷次。
  沒有白話翻譯、沒有導讀、沒有製作者自己寫的句子。
- 建置時以程式將每一段引文與原典檔**逐字比對**，對不上就不給編（`_scripts/verify.py`）。
- 地點標註必須附上原典中證明該地點的那一句；原典沒交代的標為「原典未載」，不推測。
- 地圖座標取自**哈佛・復旦中國歷史地理資訊系統（CHGIS）**，依各祖師在世年份查得的治所點。

## 每位祖師的七個面向

生平／參學歷程／開悟因緣／教學風格／歷史定位／行腳地圖／有交集的僧人或當代名人。

其中「教學風格」與「歷史定位」看起來需要評語，但本站**不下評語**——
這兩項只收原典裡**別人怎麼說他**或**他自己怎麼說**的原文（僧傳作者的敘述、
師長的印可、碑銘與諡號、祖師自述），找不到合適原文的就留白，不補寫。

## 六條生命線

六位祖師的事件排在同一條西元軸上，可以看出誰跟誰同時在世、達摩到惠能隔了多久。

⚠️ **西元年不是原典的字**。原典寫的是「隋開皇十三年」「先天二年癸丑歲」這種年號，
西元只用來決定圓點的位置，畫面上顯示的一律是原典字樣，並標明「換算待覆核」。
換算對照表在 `_data/年代對照.json`，**尚未以中研院兩千年中西曆轉換逐條覆核**
（該站查詢端點目前回 503）。

原典只寫「十月一日」「年三十二」這種沒有年份的，一律不換算、不上時間軸。
原典自身矛盾的（達摩示寂年：太和十九年 vs 干支丙辰）兩說並列，不調和。

## 古地名的今日省市

取自 CHGIS 詳目的 `present_location` 欄（來源標註復旦），依規矩收到**省・市**。
52 站中 41 站有今地；查不到的照實顯示「原典地名尚未定位」，不推算。

## 祖師畫像

採用博物館公有領域古畫（克里夫蘭美術館，CC0），每一張都標出館藏、年代、授權與詳目連結。
**只在畫中確實畫著該位祖師時才掛在他名下**：達摩頂相、達摩面壁（身旁為慧可）、
道信與童子相遇（童子即後來的弘忍）。僧璨與惠能目前查無公有領域畫像，標為「無畫像」，不以他人畫像充數。

## 行腳距離

每一站顯示「距上一站幾公里、隔了幾年」，走完整位祖師後給總距離與逐段清單。

⚠️ 距離是用歷史地理系統查到的**治所座標算的球面直線距離**，
**不是原典的字**，也不是他實際走的路——翻山繞路一定更遠。
尚未定位的站不計入，並照實說明跳過幾站。
年差只在兩站的年號都查得到西元時才給，否則標「原典沒有記下兩站的年份」。
