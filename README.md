# 禪宗．祖師行腳

達摩 → 慧可 → 僧璨 → 道信 → 弘忍 → 惠能，六位祖師走過的路、遇見的人、說過的話。
寶嚴山寶嚴禪寺．兒童互動教材。

## 這個站的規矩

- **畫面上祖師說的每一句話，逐字出自原典**，附經號、卷次。
  沒有白話翻譯、沒有導讀、沒有製作者自己寫的句子。
- 建置時以程式將每一段引文與原典檔**逐字比對**，對不上就不給編（`_scripts/verify.py`）。
- 地點標註必須附上原典中證明該地點的那一句；原典沒交代的標為「原典未載」，不推測。
- 地圖座標取自**哈佛・復旦中國歷史地理資訊系統（CHGIS）**，依各祖師在世年份查得的治所點。
